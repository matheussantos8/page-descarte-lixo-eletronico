# ♻️ Landing Page - Descarte de Lixo Eletrônico

Uma página web informativa e direta, desenvolvida para conscientizar sobre a importância do descarte correto de resíduos eletrônicos e indicar como proceder com materiais que não têm mais utilidade.

---

## 📝 Sobre o Projeto

O lixo eletrônico é um dos grandes desafios ambientais da atualidade. Esta landing page foi criada para:
- Informar sobre os perigos do descarte inadequado.
- Educar sobre o que é considerado lixo eletrônico.
- Promover práticas de sustentabilidade.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido de forma simples e eficiente utilizando:
- **HTML5**: Estruturação de conteúdo.
- **CSS3**: Estilização, layout e responsividade.
- **Imagens**: Recursos visuais para ilustrar o tema.

---

## 🚀 Como visualizar o projeto

Como se trata de uma página estática, você não precisa instalar nada!

1. Faça o download ou clone este repositório:
   ```bash
   git clone [https://github.com/matheussantos8/page-descarte-lixo-eletronico.git](https://github.com/matheussantos8/page-descarte-lixo-eletronico.git)
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo index.html em qualquer navegador (Chrome, Edge, Firefox, etc.).

---

## 📂 Estrutura de Arquivos

O repositório está organizado da seguinte forma:

* `index.html`: Arquivo principal com a estrutura da landing page.
* `/css`: Pasta contendo as folhas de estilo para o design e layout.
* `/imgs`: Pasta com as imagens e ícones utilizados no site.
* `/html`: Contém páginas secundárias ou componentes adicionais do projeto.
