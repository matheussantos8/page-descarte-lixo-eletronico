Sobre o Projeto Descarte Correto

Uma iniciativa para promover o descarte responsável de pilhas e baterias, contribuindo para um futuro mais sustentável.

O Projeto

O Descarte Correto é uma plataforma web desenvolvida como parte de uma atividade de extensão universitária, com o objetivo de conscientizar e facilitar o descarte adequado de pilhas e baterias. O projeto aborda um problema ambiental crítico: a contaminação causada pelo descarte incorreto desses materiais.

Objetivos

  • Educar sobre os impactos ambientais das pilhas e baterias
  • Fornecer informações sobre pontos de coleta
  • Promover práticas sustentáveis de descarte
  • Contribuir para a preservação do meio ambiente

Sobre o Desenvolvedor

Este projeto foi desenvolvido por Matheus Santos da Silva, estudante de Análise e Desenvolvimento de Sistemas na Uninassau. Como parte de uma atividade de extensão acadêmica, o projeto foi criado para demonstrar conhecimentos em desenvolvimento web e contribuir com questões ambientais relevantes.

Tecnologias Utilizadas

  • HTML5: Estrutura semântica da página
  • CSS3: Estilização e responsividade
  • JavaScript: Interatividade (futuras implementações)
  • Font Awesome: Ícones vetoriais

Contexto Acadêmico

Este projeto foi desenvolvido no contexto de um Hackathon Comunitário como atividade de extensão universitária. A iniciativa visa não apenas cumprir requisitos acadêmicos, mas também gerar impacto positivo na comunidade, promovendo a conscientização ambiental e incentivando práticas sustentáveis de descarte de resíduos.

Impacto Ambiental

As pilhas e baterias contêm metais pesados como chumbo, cádmio e mercúrio, que podem contaminar o solo e a água se descartados incorretamente. Este projeto busca minimizar esses impactos através da educação e facilitação do descarte responsável, contribuindo para um futuro mais sustentável.
